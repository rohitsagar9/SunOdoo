# SunPower static barcodes

Every catalogue item has a Code 128 barcode SVG in its category folder.

- **panels/** — 1 barcode (PANEL)
- **inverters/** — 5 barcodes (INVERTER)
- **batteries/** — 2 barcodes (BATTERY)
- **charge-controllers/** — 1 barcode (CHARGE_CONTROLLER)
- **structures/** — 5 barcodes (STRUCTURE)
- **cables/** — 2 barcodes (CABLE)
- **bos/** — 5 barcodes (BOS)
- **services/** — 3 barcodes (SERVICE)
- **tools/** — 10 barcodes (TOOL)

A machine-readable index is available at `manifest.json`. Rebuild with `npm run assets`.
